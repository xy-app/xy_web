# 等待元素呈现 (WebWaitPresence)

显式等待目标元素节点被加载并挂载到页面 DOM 结构中（不论当前视觉上是否可见）。

## 运行参数

* **浏览器会话 (driver)**
> 浏览器会话句柄标识。若不填写，默认使用当前活动会话。

* **目标元素 (element)**
> 目标元素的定位表达式。

* **定位策略 (y)**
> 查找元素使用的匹配策略（如 css、xpath、id、name、text、class）。

* **超时时间 (	imeout)**
> 最大等待时间，单位为秒（默认 60 秒）。

* **等待模式 (mode)**
> 等待匹配模式：One（等待单个元素呈现）或 All（等待所有匹配项呈现）。

## 输出

> 无。元素就绪后继续执行，若超时未出现则报错。

# 提取网页表格/列表数据

自动识别并提取网页中的 `<table>` 表格数据或 `<ul>/<ol>`/卡片式列表，转换为二维结构化数据并存入变量。

## 运行参数

* **驱动 (`driver`)**
> 浏览器驱动对象或会话标识。如果不填写，默认使用当前活动浏览器会话。

* **目标元素 (`element`)**
> 表格或列表容器的选择器（如 `table`、`tbody`、`ul.items`、`.data-grid`）。

## 输出

* **提取数据 (`value` / `rows`)**
> 提取的二维文本数组 JSON 字符串。
* **数据行数 (`count`)**
> 成功提取到的总行数。

# 等待元素可见(定位符) (WebWaitVisibilityByLocator)

基于定位表达式，显式等待目标网页元素变为可见或隐藏状态。

## 运行参数

* **浏览器会话 (driver)**
> 浏览器会话句柄标识。若不填写，默认使用当前活动会话。

* **目标元素 (element)**
> 待检测元素的定位表达式。

* **定位策略 (y)**
> 查找元素使用的匹配策略（如 css、xpath、id、name、text、class）。

* **可见性条件 (isibility)**
> 预期的可见性状态：Visible（等待元素呈现可见）或 Invisible（等待元素隐藏消失）。

* **等待模式 (mode)**
> 等待匹配模式：One（等待单个元素）、Any（等待任一元素）、All（等待所有元素）。

* **超时时间 (	imeout)**
> 最大等待时间，单位为秒（默认 60 秒）。

## 输出

> 成功检测到可见性变化的元素对象。

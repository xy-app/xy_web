# 打开网页 (WebOpen)

启动或接管浏览器并访问指定网页，支持 Chrome 与 Edge 浏览器。支持通过用户数据目录与配置文件保留登录态与扩展设置。

## 子流程

> 不支持

## 运行参数

* **网页地址 (url)**
> 待访问的目标网页地址。以 http:// 或 https:// 开头；若是本地文件，则以 ile:/// 开头。

* **浏览器类型 (rowser)**
> 目标浏览器类型，可选 Chrome 或 Edge。

* **用户数据目录 (user_data_folder)**
> 浏览器用户数据目录路径。若配置此项，可保留登录状态、历史记录与扩展插件；若与当前运行浏览器的默认目录一致，建议先关闭对应浏览器以避免占用冲突。

* **配置目录名称 (profile_directory)**
> 浏览器配置文件目录名称（例如 Default 或 Profile 1）。

## 输出

> 浏览器会话句柄标识（字符串类型），用于后续网页元素交互动作。

## 注意事项

* 支持快速接管正在运行的浏览器或启动全新浏览器会话。
* 若使用自定义用户数据目录，可无缝保留已有登录状态。
* 由于操作系统安全机制限制，请避免以极端管理员权限混合启动普通用户权限浏览器。

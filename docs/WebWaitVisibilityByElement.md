# 等待元素可见 (WebWaitVisibilityByElement)

基于已知元素句柄，显式等待该元素在页面中的可见性状态发生指定变化（呈现可见或隐藏消失）。

## 运行参数

* **浏览器会话 (driver)**
> 浏览器会话句柄标识。若不填写，默认使用当前活动会话。

* **目标元素 (element)**
> 已获取到的网页元素句柄对象。

* **可见性条件 (isibility)**
> 预期的可见性状态：Visible（等待元素显示可见）或 Invisible（等待元素隐藏消失）。

* **超时时间 (	imeout)**
> 最大等待时间，单位为秒（默认 60 秒）。

## 输出

> 等待就绪的网页元素对象。

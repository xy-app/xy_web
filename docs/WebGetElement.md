# 获取网页元素 (WebGetElement)

在当前网页中通过多种定位策略定位并获取指定的网页元素，用于后续的点击、输入、等待或属性读取。

## 运行参数

* **浏览器会话 (driver)**
> 浏览器会话标识或父元素对象（用于层级查找子元素）。若不填写，默认使用当前活动会话。

* **元素定位表达式 (element)**
> 元素的定位表达式内容（如 CSS 选择器、XPath 路径、ID 或文本内容）。

* **定位策略 (y)**
> 查找元素使用的匹配策略，支持：css（CSS选择器）、xpath（XPath表达式）、id（元素ID）、
ame（名称）、	ext（文本内容）、class（类名）。

## 输出

> 定位到的网页元素对象标识（字符串类型），可传递给后续元素操作指令。
